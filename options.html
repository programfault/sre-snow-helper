SRE Helper Options

ServiceNow flows, runnable services, and notification settings are saved locally and sync to the side panel in real time.

Fixed columns name,label,display,value,type. A repeated name = candidate values for one field (no longer a unique key). label is what a param with type: option looks up to build its radio choices (display shown, value filled). Edit rows via the per-row Edit button, or paste many rows at once in the CSV editor.
Paste rows — one per line, columns in order name,label,display,value,type. type may be omitted (defaults to string). Quote a field with double quotes if it contains a comma / quote / newline. Saving replaces the whole table.

Duplicate name rows are allowed.
One shared document of reusable steps. ServiceNow flow: items reference them via ref:. Params here (${param0}...) resolve inside these steps' forms.
One shared document of runnable services (top-level services: list). Each entry is an API call or a type: group (whose nested services: run top to bottom). Variables are written ${name}; when a name matches an output.alias of an earlier service in the same group it is chained automatically, otherwise it is prompted as an input in the side panel.

Ringtone library

Upload mp3 / wav / ogg files. Audio is stored as base64 in chrome.storage.local (default 5 MB total; if you need more we can request unlimitedStorage). Use the ▶ to preview, Del to remove. A ringtone referenced by any rule can't be deleted until the rule is unlinked.

Space rules

Each rule maps a Google Chat Space (matched by its sidebar name) to a ringtone. When new unread messages appear, the rule enters ALERTING and rings every N seconds until the Space is read or max repeats is reached.
